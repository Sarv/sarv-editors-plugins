The plugin runs inside the editor with no window of its own. Your page talks to it with postMessage: you ask for the document, it answers with the content, you put that content wherever you want. Five steps, all in the page that embeds the editor.

1Load the plugin for this client

Add this to the config you hand to DocsAPI.DocEditor. The URL and guid below are this plugin's real ones, read off the running copy - copy the block as it stands. Clients that should not have the export simply do not get it.


        


        

            
2Add the target element

            
Anywhere in your page - this is where the document will land.

            
<div id="output"></div>

        


        

            
3Listen, and keep the sender

            
The plugin announces itself once it starts. Hold on to
               event.source - that is the only handle you can reply to.

            
const CHANNEL = "sarv-content-export";
let plugin = null;

window.addEventListener("message", (event) => {
  const data = event.data;
  if (!data || data.channel !== CHANNEL) return;

  if (data.type === "ready") {
    plugin = event.source;
    plugin.postMessage({ channel: CHANNEL, type: "ack" }, "*");
  }
});

        


        

            
4Ask for the document

            
Call this from your own Submit or Preview button. Leave
               format out to use whatever the Settings tab says.

            
Wait for ready first. The plugin starts after the document
               does, so onDocumentReady is too early - plugin is still
               null there. Gate on step 3 having run: enable your button in the
               ready branch, or queue the request and send it from there.

            
function requestContent(format) {         // "html" | "markdown" | omit
  plugin.postMessage(
    { channel: CHANNEL, type: "extract", requestId: "req-1", format },
    "*"
  );
}

        


        

            
5Inject the answer

            
The reply arrives in the same listener you wrote in step 3.
               css and scope come with HTML only, and reproduce the
               real page width, margins and default font - drop them and you get bare content.

            
if (data.type === "result") {
  const box = document.getElementById("output");

  if (data.format === "markdown") {
    box.textContent = data.content;              // raw Markdown
  } else {
    box.className = data.scope || "";            // page-geometry wrapper
    box.innerHTML = (data.css ? "<style>" + data.css + "</style>" : "")
                  + data.content;
  }
}

if (data.type === "error") {
  console.error("export failed:", data.message);
}

        


        

            
+Open this window from your page

            
Optional - a Settings button in your own toolbar.

            
plugin.postMessage({ channel: CHANNEL, type: "openSettings" }, "*");

        


        

            
Every message, both ways

            

                
You sendWhat it does

                
ackConfirms you are listening. Stops the ready beacon.

                
extractReturns the document. Optional format, options, requestId.

                
getSettingsAnswers with the current settings.

                
setSettingsOverwrites settings from your page.

                
openSettingsOpens this window.

                
You receivePayload

                
readyguid, editor, settings - repeated once a second until you ack (60 tries, then it gives up)

                
resultrequestId, format, content, css, scope, meta

                
errorrequestId, message

                
settingssettings - also sent whenever they change here

            

            
Every message carries
               channel: "sarv-content-export"; ignore anything that does not.
